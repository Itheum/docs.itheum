## Project Agenta

Project Agenta is Itheum's latest pilot. It builds a universal trust fabric for agents and machines.

Agents need trustworthy ways to identify participants, apply permissions, and exchange value. The pilot explores those capabilities using Itheum's existing infrastructure for ownership, privacy, and programmable rights.
