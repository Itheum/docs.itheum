# Project Agenta FAQ

## Is Project Agenta a separate token or protocol?

No. Project Agenta is an Itheum pilot. It does not introduce a separate token.

## What does the pilot test?

The pilot tests a universal trust fabric for agents and machines. It focuses on verifiable context, programmable permissions, and trusted exchange.

## How does Itheum support the pilot?

Itheum provides the infrastructure primitives. These include data ownership, privacy controls, storage, licensing, and programmable assets.

## What role does $ITHEUM have?

$ITHEUM remains the governance and coordination token for Itheum's public-goods infrastructure. Governance determines its future direction and ecosystem funding.

## What happens to earlier Itheum products?

Some earlier user interfaces have reached End-of-Support. Their underlying smart contracts remain deployed. See [sunsetting-earlier-versions-v0-v2](sunsetting-earlier-versions-v0-v2/ "mention") for product-specific guidance.
