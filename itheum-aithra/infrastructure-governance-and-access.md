# Infrastructure, Governance, and Access

Project Agenta builds on Itheum's open-source public-goods infrastructure. The pilot does not introduce a separate token.

Itheum Gateways offer enterprise access through tools and APIs. Public infrastructure usage can use stablecoins and network tokens. Gateways can support web2 payment rails, including USD and credit cards.

### $ITHEUM governance

The $ITHEUM token coordinates decisions about open-source direction, roadmaps, public-goods funding, and ecosystem benefits. Governance also determines future token burns and revenue allocation.
