# Project Agenta: Overview

## Project Agenta

Project Agenta is Itheum's pilot for a universal trust fabric. It focuses on the relationships between agents, machines, data, and value.

The pilot builds on Itheum's infrastructure for programmable ownership, privacy, storage, and licensing. It investigates how agents can use these primitives to establish trusted interactions.

### What the pilot explores

* **Identity and accountability** — establishing who or what participates in an interaction.
* **Permissions and rights** — expressing what an agent or machine may access or do.
* **Trusted exchange** — connecting data, services, and value through auditable rules.

{% hint style="success" %}
Project Agenta is a pilot. Its scope and implementation can evolve as we validate the trust-fabric model.
{% endhint %}
