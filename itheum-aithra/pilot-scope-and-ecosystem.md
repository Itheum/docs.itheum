# Pilot Scope and Ecosystem

Project Agenta is the current pilot for Itheum's agent and machine trust-fabric thesis. It builds on ecosystem experience with data rights, licensing, and programmable assets.

The pilot focuses on workflows where an agent or machine needs trustworthy context, explicit permissions, and a defined exchange of value. Itheum infrastructure remains the foundation for those workflows.

### Related ecosystem work

Sigma Music demonstrates Itheum capabilities for music data tokenization and IP licensing. It remains separate from Project Agenta, while providing useful experience with rights-aware digital assets.

Itheum Gateways provide enterprise-oriented access to the underlying infrastructure.
