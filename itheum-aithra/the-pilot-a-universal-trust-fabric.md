# The Pilot: A Universal Trust Fabric

{% hint style="success" %}
Project Agenta explores trust infrastructure for autonomous and machine-mediated interactions.
{% endhint %}

Agents increasingly act on behalf of people, services, and organizations. Machines also make or execute decisions without a human in each interaction. These systems need a shared way to establish trust.

Project Agenta pilots a universal trust fabric for those interactions. Itheum's infrastructure supplies the underlying primitives for ownership, privacy, licensing, and programmable exchange.

### Why a trust fabric

Trust must travel with an interaction. Participants need clear rights, verifiable context, and enforceable rules.

The pilot tests how these elements can work across agents and machines. It does not assume one network, agent framework, or application.

This approach supports agentic workflows while preserving participant control.
