# Project Agenta Pilot Roadmap

Project Agenta validates Itheum's universal trust-fabric thesis through a focused pilot. The roadmap follows outcomes rather than fixed release dates.

| Stage | Focus           | Outcome                                                 |
| ----- | --------------- | ------------------------------------------------------- |
| 1     | Trust model     | Define the participant, permission, and exchange model. |
| 2     | Pilot workflows | Test the model across agent and machine interactions.   |
| 3     | Interfaces      | Connect the model to Workspace, SDK, and MCP workflows. |
| 4     | Evaluation      | Use pilot results to determine the next product scope.  |

{% hint style="info" %}
This is a pilot roadmap. Details can change as validation progresses.
{% endhint %}
